# Real-project examples

Eleven episodes from two real analysis projects, anonymised: no result values, sample or cohort labels, gene names, job ids or cluster paths. Each page has the questions to ask first, what happened, what the human decided, and what would have happened without the tool.

Tool text (notices, cards, verify output) is regenerated on a synthetic fixture, not quoted from the projects; each page says which parts are recorded and which are regenerated. The pages are grouped by the control point they show.

## Limits

- The E04 librarian block is illustrative: that dossier did not exist then, no external search was made, and no researcher answer is recorded.
- E06 describes 0.9.44 blocking from the changelog; the notice shown is the current re-pin text.
- No use of `freeze` or track-changes appears in either project (the features came later), so those cards are regenerated shapes.
