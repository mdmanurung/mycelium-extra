# Real-project examples

These three episodes come from real analysis projects, anonymised: no result values, sample or cohort labels, gene names, job ids or cluster paths. Tool text (notices, cards, verify output) is regenerated on a synthetic fixture. Each page says which parts are recorded.

![E01 asks what counted as consent, E03 asks whether the report matches its score direction, and E07 asks what was actually recorded. The other eight cases remain available in the repository.](../figures/example-lessons.svg)

Choose a case by the question it teaches. The three cases below are on the site; the other eight are linked separately in the repository.

- [E01. A chat "yes" is not an approval](E01-chat-yes-is-not-consent.md) (consent)
- [E03. Sign-flipped comparison fixed through a one-step plan](E03-sign-flipped-comparison.md) (honesty)
- [E07. verify: planned command unrecorded, unplanned script ran](E07-verify-unplanned-and-unrecorded.md) (honesty)
- [Track changes: a real report](track-changes.md): the HTML report `track-changes` writes.

The other eight are on [GitHub](https://github.com/mdmanurung/mycelium-extra/tree/main/docs/examples).
