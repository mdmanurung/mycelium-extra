# Manuscript reproducibility readiness checklist

Use labels `established`, `failed`, `not checked`, `unavailable`—never assert all are established because a convention is installed.

- [ ] Main figure and supplementary table map includes exact script and source tables.
- [ ] Accessions/controlled-access instructions and transformation chains are documented.
- [ ] Sample metadata primary keys and donor/visit mapping match input datasets.
- [ ] Pseudobulk uses intended raw summed integer counts; scale and assay are explicit.
- [ ] Composition denominators/zero policies explicit and checked.
- [ ] Formula, nuisance design, contrast orientation, multiplicity family and exclusions fixed.
- [ ] Expert annotation/revised labels and any dropped cells have versioned rationales.
- [ ] Factor projections preserve feature identity/order; uncertainty caveat provided.
- [ ] Published panels export complete numeric and categorical aesthetics in source data.
- [ ] Figures are visually inspected, with legible text, categorical identity and units.
- [ ] Environment versions and exact rerun entry point documented.
- [ ] Objective validators have tests demonstrating red on failure and green on control.
- [ ] A rerun was actually performed where claimed; missing/controlled data are acknowledged.
- [ ] User approved consequential choices; `verify` results are not described as proof of biological validity.
