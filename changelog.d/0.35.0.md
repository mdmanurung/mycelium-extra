## [0.35.0] - unreleased

Method mode for the research loop, and a bridge to the tusoskill skill.

### Added

- **iterate:** `--mode method`. The root takes an iteration floor and a benchmark card as plan rows you approve; neither has a default. Ideas from tusoskill (no licence line), rewritten with no copied code or text: a hash-frozen evaluator, a baseline and a sanity node before candidates count, and a floor that stops the loop. tusoskill's floor of 50 is shown as one sourced option.
- **iterate:** `tree.py freeze-evaluator` writes SHA-256 hashes of the card and the protected files; `check-evaluator` compares them (exit 0 match, 3 changed or missing, 2 no tree). `add --kind baseline|sanity|candidate`. No node runs before the freeze, and a run or answer is refused while a hashed file differs. Only answered candidates count toward the floor.
- **iterate:** optional arena step. `plan --rubric` fixes the rubric before sibling candidates run, and `tree.py arena A B --winner A` records the comparison. Idea from pstack's `arena` (MIT, cursor/plugins).
- **hooks:** `hooks/loop_guard.py` refuses (`block`) or notes (`warn`) a Write, Edit, MultiEdit, NotebookEdit, apply_patch (Codex), or OpenCode edit, write or patch call on a hashed evaluator file, and reports a changed evaluator at turn end. Wired in `hooks/hooks.json`, `hooks/codex.json` and `opencode/index.js`.
- **hooks:** tusoskill bridge. When the repo holds a `state/state.json` of tusoskill's shape, the guard's Stop check runs that skill's own `biomni_method_state.py stop-check` (path overridable with `MYCELIUM_TUSOSKILL_SCRIPT`) and blocks while it exits 3. It is silent when the script is absent. The message names `record-blocker --kind user` as the escape, to run only when the user says to stop. No tusoskill file is copied.
- **tests:** `tests/fixtures/tusoskill/` holds a state file and a stub script for the bridge tests.
