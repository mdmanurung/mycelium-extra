# Claude synthesis

Use this section order. The order and issue IDs are fixed; deciding which recommendation to accept requires evidence and judgment, not a vote.

1. **Reviewer status:** name who actually ran, the packet version/content each saw, redactions, failures, and gaps. An unavailable or invalid review is not a negative finding.
2. **Agreement:** independently raised concerns with each original issue ID and evidence. Similar wording without the same substantive concern is not agreement.
3. **Biomni-only concerns** and **Codex-only concerns:** retain unique findings and uncertainty.
4. **Conflicts:** present materially different recommendations side by side; do not force consensus.
5. **Accepted changes:** proposed plan amendments with rationale, supporting evidence, and validation. These remain proposals until the user requests a revised plan.
6. **Rejected changes:** recommendation, reason, and evidence.
7. **User decision required:** choices that change the scientific question, estimand, data, or material trade-off. State the options and consequences.

If one reviewer is unavailable, preserve its status in every relevant section; do not label single-reviewer findings as agreement. If both are unavailable, report that independent review did not occur. Do not edit the original plan, `.living/`, approval state, or repository files. A later revised plan receives a new approval context before execution. Reviewer provenance in a future Source cell does not itself authorize any script or command.
