# Audit of the generated HTML, 2026-11

Targets: `assets/viewer.css`, `assets/viewer.js`, `assets/journal.js`, `scripts/render.py`, `scripts/journal.py`, and the pages in `docs/examples/`. Mode: Operate/Read (restraint, not expression). Method: `impeccable detect` on the assets and the three example pages, then a code read against DESIGN.md. Contrast is computed from the DESIGN.md hex values (WCAG 2.x relative luminance). No browser was available, so nothing was checked as rendered.

Status `fix` rows were implemented in this commit. Status `triage` rows are left for the user to decide. File:line for `fix` rows is the line before the fix (`HEAD` of `main` at 0c74d72); for `triage` rows it is the current line.

Severity: high = a state reads as the wrong thing or content is unreachable; medium = a state is unclear or a standard is missed; low = polish.
