# Destination shapes

Name the destination first. It sets the scope, and scope decides which tickets belong. Write it in one or two lines in `## Destination`.

Read this when you chart a map and the user has not said what the end looks like.

| Shape | Looks like | Typical tickets |
|---|---|---|
| An approved analysis plan | A grill plan the user can approve for one analysis. The map ends when every impactful choice has a settled answer. | Which comparison is the question; which model family; which covariates and random effects; which filters; what counts as a replicate (donors). |
| A decision locked before planning | One call that everything else waits on: which cohort, which case definition, which time anchor, which reference. The map ends when that call is made and recorded. | Inclusion criteria; what the collaborator can supply; what each definition would change in the headline numbers. |
| A figure set for a manuscript | The list of panels, each tied to the claim it supports and the analysis that makes it. The map ends when each panel has a row in a plan or a reason to drop it. | Which claims the paper makes; which panel carries each; which panels need new analysis; which data are not ready. |

When none fits, write the end in the user's words and check that you can tell, from outside, whether the map has reached it.

Out of scope follows the destination. If the destination is a locked cohort decision, the downstream model choice is out of scope. Close it with a one-line reason.
